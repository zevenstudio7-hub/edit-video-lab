# Gemini Video Lab

## Objetivo

Construir un sistema de edición inteligente de contenido grabado por el usuario usando principalmente Gemini para análisis e interpretación y Remotion para composición, motion graphics y render.

## Flujo base

Google Drive / material grabado
→ estrategia y plan de edición
→ Gemini
→ agente de desarrollo
→ Remotion
→ video final

## Principios

- editar primero material grabado por el usuario;
- priorizar control y reproducibilidad;
- reutilizar componentes;
- evitar generar código distinto para cada video cuando pueda resolverse con componentes;
- no agregar infraestructura que todavía no sea necesaria;
- construir la biblioteca audiovisual a partir de casos reales.
